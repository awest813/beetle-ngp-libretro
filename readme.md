# Beetle NeoGeo Pocket / NeoGeo Pocket Color

libretro emulation core for SNK's NeoGeo Pocket and NeoGeo Pocket Color handhelds.

- **Platforms:** 30+ targets including Windows, Linux, macOS, Android, iOS, 3DS, Switch, Vita, PSP, GC/Wii/WiiU, Dreamcast
- **Dreamcast:** Full standalone launcher + RetroArch static integration with PVR hardware rendering, VMU flash mirroring, and Maple input. See [BUILDING.md](BUILDING.md) for build/deploy instructions.
